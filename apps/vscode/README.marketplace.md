OpenProvider is a coding agent built around **free API providers** — NVIDIA Build, Groq, Cerebras, Gemini, and OpenRouter. It's a fork of [Cline](https://github.com/cline/cline), focused on making it easy to code with zero-cost model access instead of a single paid backend.

OpenProvider can create and edit files, run terminal commands, use the browser, and extend itself through the Model Context Protocol (MCP) — always with your permission before anything happens to your workspace.

## Why a fork focused on free providers

Most coding agents assume you're paying for a single vendor's API. OpenProvider is built the other way around: pick from several free-tier providers, see how much quota you have left, and stay in control when a provider is exhausted or rate-limited instead of being silently switched or blocked.
